# Remote TG

Агент для своего Windows-ПК: окно с тёмной панелью, значок в трее и управление из Telegram. Процесс виден в диспетчере задач. Команды принимает только тот, кто ввёл код привязки с экрана этого ПК.

Лицензия: GPL-3.0.

## Что умеет

1. Привязка по коду с экрана, дальше только эти Telegram ID.
2. Роли: владелец, оператор, наблюдатель.
3. Несколько аккаунтов в одном конфиге.
4. Запасной токен бота, если основной не отвечает.
5. Журнал действий.
6. Окно WebView2, тёмная тема, русский интерфейс.
7. Значок окна, трея и favicon страницы.
8. Трей: открыть, пауза, выход. Закрытие окна прячет его в трей.
9. `start.vbs` запускает pythonw без консоли.
10. Автозагрузка — ярлык в папке Startup. Его видно в автозагрузке Windows, удаление ярлыка отключает запуск.
11. Запрос прав администратора через обычное окно UAC, без обхода.
12. Обзор: CPU, ОЗУ, диски, сеть, аптайм, батарея.
13. Бот сам ходит в Telegram, белый IP и проброс портов не нужны.
14. Файлы: диски, папки, скачать в чат, загрузить на ПК, создать папку, переименовать.
15. Удаление только файла и только с подтверждением.
16. Процессы: список, завершение, запуск программы.
17. Службы: список, старт, остановка.
18. Скриншот рабочего стола по запросу.
19. Питание: блокировка, сон, перезагрузка, выключение, отмена таймера.
20. Буфер обмена.
21. Громкость и mute.
22. Список окон и закрытие окна.
23. Открыть файл или http(s); скачать файл по ссылке в папку.
24. Сообщения в Telegram: агент онлайн, мало места, CPU от 90%.
25. Быстрый запуск: имя и команда в окне, кнопка «Запустить», в Telegram `/apps` и `/go имя`.
26. Раздел FAQ в окне: что делает каждый элемент и как управлять программой.

Командная строка есть у владельца, каждая команда пишется в журнал. Наблюдатель видит только статус и скриншот. Оболочка, удаление, питание и остановка службы — только владелец и только после подтверждения.

Панель в окне открывается только на этом ПК. Встроенный сервер окна слушает `127.0.0.1`, в локальную сеть его не выставляем.

## Запуск

Нужны Python 3.11+ и WebView2 (в Windows 11 он уже есть).

```text
py -3 -m pip install -r requirements.txt
```

Двойной щелчок по `start.vbs` — без чёрного окна. Windows спросит UAC. То же самое делает ярлык автозагрузки.

Либо из консоли, тоже с запросом прав:

```text
pyw -3 app\main.py
```

Конфигурация и журналы лежат в `%APPDATA%\Remote TG`: `config.json`, `audit.log`, `agent.log`. В папку программы они не пишутся. Если старые файлы остались рядом с `start.vbs`, первый запуск переносит их в эту папку. Токен в репозиторий не класть.

## Первые шаги

1. В Telegram откройте @BotFather, команда `/newbot`, скопируйте токен.
2. В окне Remote TG → Настройки вставьте токен и сохраните. Запасной токен — второй бот на тот же ПК.
3. Пока аккаунтов нет, код привязки виден на обзоре. В боте: `/pair КОД`. Первый аккаунт становится владельцем.
4. Следующих людей добавляйте кнопкой «Выдать код» и ролью. Под списком роли написано, чем она отличается. Код живёт 10 минут. В чат он сам не отправляется.

Роли: владелец — всё, оператор — файлы, процессы, окна, звук и буфер, наблюдатель — статус и скриншот.

## Автозагрузка

Двойной щелчок по `install_autostart.vbs` или кнопка в настройках. Ярлык называется `Remote TG` и лежит в папке автозагрузки пользователя. Чтобы выключить, удалите ярлык там или нажмите кнопку ещё раз. Скрытой задачи в планировщике нет: при каждом входе Windows снова показывает UAC.

## Окно и бот

Одни и те же действия доступны в окне и в Telegram. Внизу чата есть кнопки. `/help` показывает команды этой роли. Опасное действие в окне ждёт галочку «подтверждаю», в Telegram — кнопки «Да» и «Нет».

Раздел «Запуск» хранит до 24 программ в конфиге пользователя. «Обзор» подставляет путь к файлу, «Запустить» стартует сохранённую команду. В боте список — `/apps`, запуск — `/go имя`. Раздел «FAQ» в окне описывает шапку, каждую страницу и команды Telegram.

Файл в чат сохраняется в текущую папку (`/cd`) или в «Загрузки». Подпись с путём `C:\...` задаёт другую папку. Из Telegram бот принимает файл до 20 МБ и отправляет до 49 МБ.

`config.example.json` показывает поля конфига. Рабочий файл программа создаёт в `%APPDATA%\Remote TG`.
